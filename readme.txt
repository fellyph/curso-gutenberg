## Módulo Intermediário

### Aula 8 - Trabalhando com Atributos de Bloco
Definir, usar e validar atributos (string, boolean, array, object). Sincronização entre editor e frontend.

### Aula 9 - Componentes do Block Editor
Uso de RichText, MediaUpload, InspectorControls, BlockControls e ColorPicker.

### Aula 10 - Block Supports API
Cores, tipografia, espaçamentos, alinhamentos e outras configurações nativas via block.json.

### Aula 11 - InnerBlocks e Blocos Aninhados
Criar blocos container, templates obrigatórios e allowed blocks.

### Aula 12 - Block Variations e Patterns
Criar variações de blocos existentes e padrões reutilizáveis.

## Módulo Avançado

### Aula 13 - Blocos Dinâmicos com PHP
Server-side rendering, blocos que buscam dados do banco de dados.

### Aula 14 - Block Context API
Comunicação entre blocos pai e filho, compartilhamento de dados.

### Aula 15 - WordPress Interactivity API
Adicionar interatividade no frontend sem frameworks externos.

### Aula 16 - Criando Plugins de Sidebar
Estender o editor com painéis personalizados usando SlotFill.

### Aula 17 - Internacionalização (i18n)
Traduzir blocos para múltiplos idiomas com wp-i18n.

## Módulo de Qualidade e Deploy

### Aula 18 - Testes com Playwright
Escrever testes end-to-end para seus blocos.

### Aula 19 - Performance e Otimização
Lazy loading, code splitting, otimização de assets.

### Aula 20 - Acessibilidade em Blocos
ARIA labels, navegação por teclado, contraste de cores.

### Aula 21 - Publicando seu Plugin
Preparar e submeter um plugin de blocos para o diretório oficial.

## Aulas Bônus - Projetos Práticos

### Bônus 1 - Criando um Bloco de Testimonials
Projeto prático com InnerBlocks, estilos e variações.

### Bônus 2 - Bloco de Cards com Query Loop
Bloco dinâmico que busca posts do WordPress.

### Bônus 3 - Bloco Interativo de FAQ/Accordion
Usando Interactivity API para toggle de conteúdo.
